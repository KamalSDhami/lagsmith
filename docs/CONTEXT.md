## Architecture
- **Contract:** `src-tauri/src/model.rs` is mirrored by `src/types.ts` (includes `AdminEvent`, `AdminResult`, `DumpAnalysis`). Read commands take no arguments. User-level actions go through `apply_changes(title, changes)`, `undo_change(id)`, `get_history`.
- **Code:** `scan/*` (diagnostics), `actions/*` (startup, Game Mode, Game Bar, power overlay, handle-based cache clean), `admin/*` (private DACL named pipe + `runas` launcher + `run_admin_task` Channel command).
- **Elevated helper (`src-tauri/helper/`):** `SetDefaultDllDirectories(LOAD_LIBRARY_SEARCH_SYSTEM32)`, `protected::gate()`, strict arg allow-list (`EXIT_BAD_ARGS = 2`, `EXIT_GAME_RUNNING = 3`, `EXIT_PIPE_REFUSED = 4`, `EXIT_SYSTEM_DLL = 5`), `GetNamedPipeServerProcessId` + `lagsmith.exe` path verification, `SECURITY_IDENTIFICATION` pipe client. Implements `restore-point` (`srclient.dll` `SRSetRestorePointW`), `sfc` (System32 `sfc.exe`, UTF-16LE streaming), `dism-restorehealth` (System32 `dism.exe`, `\r` `%` + `3010` + `0x800f081f`/`0x800f0915`), and `analyze-dumps` (`dbgeng.dll` from System32, empty symbol path, loaded + unloaded module resolution for `vgk.sys`).
- **Frontend:** `RepairPage.tsx` (SFC, DISM, Restore Point with live progress) and `CrashPage.tsx` ("Analyze dumps" + suspect driver display), coordinated by single-task lock in `useSystemData.ts`.
- **Bundling & Security:** `tauri.conf.json` sets strict CSP, `bundle.externalBin = ["binaries/lagsmith-helper"]`, `bundle.windows.nsis.installMode = "perMachine"`. Capabilities hold only `allow-<command>` (list in `build.rs`). No shell spawning from the UI.
